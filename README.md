# 👾 YURI DEV HUB

Este é o meu portfólio de desenvolvimento de sistemas e jogos independentes, construído em **Python** utilizando o framework **Flask**.

## 🚀 Tecnologias Utilizadas
* Python 3
* Flask (Backend leve)
* Tailwind CSS (Visual moderno)
* JSON (Banco de dados estruturado)

## 📌 Como o projeto funciona
Os dados dos jogos ficam armazenados de forma limpa no arquivo `jogos.json`. O servidor Python lê esse arquivo automaticamente e atualiza a interface visual do site sem a necessidade de reajustar o código HTML.
